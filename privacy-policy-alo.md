# App Privacy Policy

## Introduction
This privacy policy outlines how your app collects, uses, and shares user data in compliance with Apple App Store and App Connect requirements. By using this app, users agree to the practices described in this policy.

---

## Data Collection

### Types of Data Collected
1. **Personal Information**:
   - Name
   - Email Address
   - Phone Number
2. **Device Information**:
   - Device ID
   - IP Address
   - Operating System
3. **Usage Data**:
   - App interactions
   - Crash logs
   - Performance metrics

### Methods of Collection
- User-provided data during registration or profile setup.
- Automatic collection through app usage.
- Third-party services integrated into the app.

---

## Data Usage

### Purpose of Data Usage
1. **App Functionality**:
   - Authentication and account management.
   - Providing core app features (e.g., messaging, calls).
2. **Analytics**:
   - Improving app performance.
   - Understanding user behavior.
3. **Notifications**:
   - Sending push notifications for updates and alerts.

### Data Retention
- Data is retained as long as necessary to fulfill the purposes outlined above.
- Users can request data deletion by contacting support.

## Data Sharing

### Third-Party Services
The app may share data with the following third-party services:
1. **Firebase**:
   - Authentication
   - Analytics
   - Cloud Messaging
2. **Apple Sign-In**:
   - For user authentication.
3. **LiveKit**:
   - For real-time communication features.

### Data Protection Measures
- All data shared with third parties is encrypted.
- Third parties are required to comply with applicable privacy laws.
